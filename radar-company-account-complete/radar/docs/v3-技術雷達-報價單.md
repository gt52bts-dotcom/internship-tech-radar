## 二、報價單功能範圍

本版本包含：

- 在 S2 排序後、S3/S4 LLM 評估前加入 `s2b_quote.py`。
- 每次執行先產生 `quotation.json` 與 `quotation.html`。
- 報價未超過上限時才執行 LLM 評估。
- 報價超過上限時自動改走 zero-token rubric fallback。
- S5 最終報告保留「報價 vs 實際」欄位，作為後續校準依據。

## 五、成本控制策略

- 不使用 Amazon Bedrock，避免模型啟用、SCP、Region 與內部審核卡點。
- 不使用 CloudFront，避免 global service 在公司帳戶受 SCP / Region 限制。
- 不使用 OpenSearch、RDS、EC2、Bedrock Knowledge Bases 等高固定成本服務。
- Anthropic API key 放在 AWS Secrets Manager，不寫入程式碼。
- EventBridge 排程預設關閉，避免部署後自動產生成本。
- 單次執行有 `MAX_RUN_USD` 上限，預設 USD 0.50。
- 超過上限時自動改走 rubric fallback，流程不中斷、token 成本歸零。
- 落地驗證結束後可執行 `cdk destroy --all` 停止資源。

## 七、報價依據

- Anthropic Claude Platform pricing：Claude Sonnet 4.5 為 USD 3 / MTok input、USD 15 / MTok output；Claude Haiku 4.5 為 USD 1 / MTok input、USD 5 / MTok output。
- 專案程式內估算：Evaluator 每候選 1,500 input / 400 output tokens；Validator 每候選 1,200 input / 300 output tokens。
- AWS serverless 服務採公司帳戶輕量落地驗證估算，實際費用以 AWS Billing 為準。

# 學校｜評分表索引

狀態：已取得 2 張國立臺灣海洋大學表單  
用途：集中管理學校端需要實習機構填寫的問卷與成績考核表，避免和國泰內部評分表混在一起。

## 已取得表單

| 表單 | 用途 | GitHub 可讀頁 |
|---|---|---|
| 國立臺灣海洋大學學生校外實習成效問卷（實習機構） | 實習機構回饋學校實習流程與實習生工作表現滿意度。 | [查看](./ntou-internship-effectiveness-questionnaire.md) |
| 學生校外實習成績考核表（實習機構主管用） | 實習機構主管評核平時表現、心得報告、考勤並給出主管評核成績。 | [查看](./ntou-internship-performance-evaluation.md) |

## 使用規則

- 學校表單與國泰內部表單分開處理，不互相套用分數。
- 成效問卷偏滿意度調查，正式勾選以公司或主管實際意見為準。
- 成績考核表可先用 `AI 模擬實習機構主管評分` 準備填答，但正式成績仍以主管簽名確認版本為準。

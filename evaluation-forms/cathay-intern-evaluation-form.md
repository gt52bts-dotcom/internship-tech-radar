# 國泰｜實習生評鑑表單

來源：國泰 CIP 表單填寫系統  
狀態：已依 2026-07-21 使用者截圖建立，並於 2026-08-21 依工作紀錄更新 25 字內主要理由與綜合回饋
用途：評估實習生在積極自發／持續學習、團隊合作、創新求變、組織認同、誠信正直等面向的表現，並填寫優點／可改善處與綜合回饋。

## 表單結構

### 積極自發、持續學習

評核文字：

1. 工作上，能主動發掘問題、分析問題與蒐集資料，以尋求新機會、新想法或是防範措施，必要時會主動向主管與同事提出建議或回饋。
2. 遇到問題時或需要有所回應時，能主動接受挑戰，並立即採取合理的行動。
3. 即使上級沒有要求，也能主動付出額外的努力，以期工作成果能超越上級的期望。
4. 積極地透過各種管道，增進自己的專業知識、技能與工作經驗。

選項：`傑出`、`優異`、`良好`、`欠佳`、`待改善`

文字欄位：`【積極自發、持續學習】優點/可改善之處`

### 團隊合作

評核文字：

1. 與團隊成員互動時，能秉持相互信任的態度，與具備不同特質的成員相處融洽。
2. 當團隊成員有所貢獻時，會適時與適度地給予鼓勵或讚許。
3. 願意無私地分享資訊、意見與資源給其他團隊成員，以助其完成工作任務。
4. 身為團隊成員能秉持各司其職、互相協調的精神，以發揮團隊之最大綜效。

選項：`傑出`、`優異`、`良好`、`欠佳`、`待改善`

文字欄位：`【團隊合作】優點/可改善之處`

### 創新求變

評核文字：

1. 工作上，展現出突破組織傳統的想法與規範的意願與行動，例如工作上持續提出新的想法或做法。
2. 呈現出接受組織變革之意願，能夠尋找屬於自己的機會並加以掌握，強化個人的競爭力。
3. 能夠結合並運用各種作業模式或流程，以期能產生新的企業作業模式。
4. 能夠接受挑戰、嶄新與複雜的概念，力求工作上的創新。

選項：`傑出`、`優異`、`良好`、`欠佳`、`待改善`

文字欄位：`【創新求變】優點/可改善之處`

### 組織認同

評核文字：

1. 實習生是否積極參與實習活動或部門、單位之活動。
2. 實習生是否認同公司的文化及經營理念。

選項：`非常認同`、`認同`、`普通`、`不認同`、`非常不認同`

### 誠信正直

評核文字：

實習期間之表現是否可確認該成員誠信正直。

選項：`是`、`否（請於下方詳述原因）`

文字欄位：`【誠信正直】優異/偏差事項`

### 綜合回饋

文字欄位：`綜合回饋`

## 目前建議填答

| 項目 | 建議評等 | 主要理由 |
|---|---|---|
| 積極自發、持續學習 | 傑出 | 主動拆解問題，持續學習雲端與 AI 工具。 |
| 團隊合作 | 優異 | 能依回饋修正方向，清楚同步進度與成果。 |
| 創新求變 | 傑出 | 將 AI 與雲端研究轉化為可複用流程。 |
| 組織認同 | 非常認同 | 遵守公司規範，重視資安、授權與成本邊界。 |
| 誠信正直 | 是 | 誠實標示驗證狀態，不誇大專案成果。 |

綜合回饋：積極正向，能將新技術整理成可追蹤成果。

## 2026-08-17 填答建議摘要

- 可爭取最高評等的面向：積極自發／持續學習、創新求變、組織認同。
- 團隊合作建議用 `優異` 而不是 `傑出`：目前有穩定 mentor 對齊、主動回報與實習生活動證據，但正式跨團隊共同交付仍較少。
- 誠信正直建議維持 `是`，並在文字欄補上「不誇大未完成驗證、不記錄敏感資訊、清楚標示證據邊界」。

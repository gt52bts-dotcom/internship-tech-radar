# 國泰｜實習生評鑑表單

來源：國泰 CIP 表單填寫系統  
狀態：已依 2026-07-21 使用者截圖建立  
用途：評估實習生在積極自發／持續學習、團隊合作、創新求變、組織認同、誠信正直等面向的表現，並填寫優點／可改善處與綜合回饋。

## 表單結構

### 積極自發、持續學習

評核文字：

1. 工作上，能主動發掘問題、分析問題與蒐集資料，以尋求新機會、新想法或是防範措施，必要時會主動向主管與同事提出建議或回饋。
2. 遇到問題時或需要有所回應時，能主動接受挑戰，並立即採取合理的行動。
3. 即使上級沒有要求，也能主動付出額外的努力，以期工作成果能超越上級的期望。
4. 積極地透過各種管道，增進自己的專業知識、技能與工作經驗。

選項：`傑出`、`優異`、`良好`、`欠佳`、`待改善`

文字欄位：`【積極自發、持續學習】優點/可改善之處`

### 團隊合作

評核文字：

1. 與團隊成員互動時，能秉持相互信任的態度，與具備不同特質的成員相處融洽。
2. 當團隊成員有所貢獻時，會適時與適度地給予鼓勵或讚許。
3. 願意無私地分享資訊、意見與資源給其他團隊成員，以助其完成工作任務。
4. 身為團隊成員能秉持各司其職、互相協調的精神，以發揮團隊之最大綜效。

選項：`傑出`、`優異`、`良好`、`欠佳`、`待改善`

文字欄位：`【團隊合作】優點/可改善之處`

### 創新求變

評核文字：

1. 工作上，展現出突破組織傳統的想法與規範的意願與行動，例如工作上持續提出新的想法或做法。
2. 呈現出接受組織變革之意願，能夠尋找屬於自己的機會並加以掌握，強化個人的競爭力。
3. 能夠結合並運用各種作業模式或流程，以期能產生新的企業作業模式。
4. 能夠接受挑戰、嶄新與複雜的概念，力求工作上的創新。

選項：`傑出`、`優異`、`良好`、`欠佳`、`待改善`

文字欄位：`【創新求變】優點/可改善之處`

### 組織認同

評核文字：

1. 實習生是否積極參與實習活動或部門、單位之活動。
2. 實習生是否認同公司的文化及經營理念。

選項：`非常認同`、`認同`、`普通`、`不認同`、`非常不認同`

### 誠信正直

評核文字：

實習期間之表現是否可確認該成員誠信正直。

選項：`是`、`否（請於下方詳述原因）`

文字欄位：`【誠信正直】優異/偏差事項`

### 綜合回饋

文字欄位：`綜合回饋`

## 目前建議填答

| 項目 | 建議評等 | 主要理由 |
|---|---|---|
| 積極自發、持續學習 | 優異 | 能主動拆解 AWS 權限、部署、CLI、成本與評估問題，並持續把成果轉成日誌、demo checklist、final proposal 素材與可回驗證據。 |
| 團隊合作 | 良好 | 單位只有一個實習職缺，團隊合作應以 mentor 對齊、主動回報、文件同步與依回饋調整方向為主要證據；目前這些面向表現穩定。 |
| 創新求變 | 優異 | 將 AI PM、Skill 積分、Evidence Ledger、Human Review Gate、Decision Layer 與 evaluation harness 結合成可追蹤流程，展現明確創新與方法整合。 |
| 組織認同 | 認同 | 能遵守公司相容紀錄方式、密鑰不入檔、private GitHub 呈現與 Notion 日誌節奏；若後續補上更多部門活動參與證據，可提升為「非常認同」。 |
| 誠信正直 | 是 | 在日誌、報告與 demo 素材中持續區分已驗證、待公司環境驗證與估算結果；不記錄 API key、AWS credentials 或敏感資訊。 |

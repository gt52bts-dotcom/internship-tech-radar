# 學校｜國立臺灣海洋大學學生校外實習成效問卷（實習機構）

來源：使用者提供 Word 檔 `國立臺灣海洋大學 學生校外實習成效問卷(實習機構).docx`  
填寫對象：實習機構  
填寫時機：實習結束時  
用途：讓學校了解實習機構對實習課程流程與實習生工作表現的滿意度，作為校方改善實習制度的參考。

## 表單處理規則

- 這張表不是國泰主管評分表，也不是 Mentor 15 項觀察表。
- 前半段「實習課程」偏向實習機構對學校流程的滿意度，不應由 AI 或實習生自行代替公司判斷。
- 後半段「對實習生的工作項目滿意度」可用目前專案證據先做填答準備，但正式勾選仍以實習機構主管或指導員意見為準。

## 基本資料欄位

| 欄位 | 內容 |
|---|---|
| 實習機構名稱 | 待公司填寫 |
| 實習機構指導員 | 待公司填寫 |
| 實習生系級 | 通訊與導航工程學系 A |
| 實習生姓名 | 待填 |
| 實習期間 | 年 月 日至 年 月 日 |

## 滿意度選項

表單選項：

- 非常滿意
- 滿意
- 普通
- 不滿意
- 非常不滿意

## 問卷項目

### 實習課程

| 題目 | 建議處理 |
|---|---|
| 實習媒合申請作業流程是否滿意 | 由實習機構依實際行政流程勾選；若公司無特別不滿，保守建議 `滿意`。 |
| 實習課程所要求實習時數是否滿意 | 由實習機構依實際工時安排勾選；若無衝突，保守建議 `滿意`。 |
| 實習課程所簽訂合約內容是否滿意 | 由實習機構依合約流程勾選；AI 不代填。 |
| 對實習名額供需是否滿意 | 由實習機構依年度招募需求勾選；AI 不代填。 |

### 對實習生的工作項目滿意度

| 項目 | AI 填答準備建議 | 依據與補強 |
|---|---|---|
| 專業知識與技能 | 滿意 | 已能完成 AWS PoC、CloudFormation、Step Functions、S3 Files 查證與文件整理；若主管認為技術掌握度超出實習期待，可改 `非常滿意`。 |
| 處事應變能力 | 非常滿意 | 遇到 AWS 權限、Lambda handler、API key fallback、PowerShell／CLI 問題時能定位原因並提出修正。 |
| 工作品質與自我管理 | 非常滿意 | Git、Notion、AI PM inbox、dashboard 與正式日誌形成可回查的工作紀錄。 |
| 語文表達 | 滿意 | 可將技術內容整理成雙週誌、final proposal 素材與主管可讀 README；若主管重視簡報與溝通表現，可再補口頭報告證據。 |
| 溝通協調能力 | 滿意 | 能依 mentor 方向調整主線並回報限制；跨同事／跨團隊互動證據仍可再補。 |
| 敬業態度 | 非常滿意 | 對日誌、驗證、敏感資訊不入檔、17:00 統整規則與 Git source of truth 都能持續遵守。 |
| 創新能力 | 非常滿意 | 建立 AI PM、Skill 積分、Evidence Ledger、Human Review Gate、Decision Layer、evaluation harness 與評分表集合。 |
| 整體工作表現 | 非常滿意 | 目前交付密度、主動性與可驗證成果完整；正式勾選仍以主管觀感為準。 |

## 其他意見欄位

| 欄位 | 建議處理 |
|---|---|
| 是否願意繼續聘雇本位實習生為公司正職員工 | 這是公司正式聘雇意願，不由 AI 代填。若公司願意，可勾 `是` 並補「若有適合職缺，可考慮延續」。 |
| 其他建議 | 可請主管填寫對學校課程安排、實習媒合或學生準備度的建議。 |

若主管需要簡短回覆，可參考：

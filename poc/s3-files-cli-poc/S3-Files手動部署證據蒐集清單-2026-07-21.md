# S3 Files 手動部署證據蒐集清單

日期：2026-07-21  
目的：保留手動 CLI 部署 S3 Files PoC 的可驗證證據，供 mentor 說明、final proposal 與日誌使用。  
安全原則：截圖或貼文字前，請遮蔽完整 AWS account ID、完整 ARN、public IP、private IP、私鑰、credential、presigned URL 與任何公司敏感資訊。

## 最少要保留的證據

### 1. 架構資源存在

建議截圖：

- AWS Console > S3 Files > File systems：顯示 file system 狀態為 `available`。
- AWS Console > S3 Files > File system detail：顯示有 mount target，狀態可用。
- AWS Console > EC2 > Instances：顯示測試 EC2 instance 狀態為 `running` 或曾經 running。
- AWS Console > S3 > Bucket > 指定 prefix：顯示測試檔案清單。

可遮蔽：

- account id。
- 完整 ARN。
- public IP / private IP。
- 完整 resource id 後半段。

保留即可：

- resource type。
- status。
- region。
- 檔案名稱。
- bucket / prefix 的非敏感名稱，若擔心可只保留前綴。

### 2. EC2 已成功 mount S3 Files

建議截圖 EC2 terminal，畫面包含：

```bash
df -h /mnt/s3files
findmnt -T /mnt/s3files
```

成功重點：

- `/mnt/s3files` 有掛載。
- `FSTYPE` 顯示 `nfs4`。
- source 類似 `127.0.0.1:/`，這是 S3 Files mount helper 的表現，不是錯誤。

### 3. S3 檔案可從 EC2 mount path 讀到

建議截圖 EC2 terminal：

```bash
ls -la /mnt/s3files
cat /mnt/s3files/hello-from-s3.txt
```

成功重點：

- `hello-from-s3.txt` 出現在 mount path。
- `cat` 能讀出原本從 PowerShell 上傳到 S3 的內容。

注意：

- 如果 file system 建立時指定 S3 prefix，mount 根目錄就是該 prefix，不需要再多進一層 `poc/`。

### 4. EC2 mount path 寫檔後，S3 能讀回

建議截圖兩段。

EC2 terminal：

```bash
echo "hello from mounted S3 Files $(date -Iseconds)" | sudo tee /mnt/s3files/hello-from-mount.txt
sync
ls -la /mnt/s3files
```

PowerShell：

```powershell
$ObjectKey = "${Prefix}hello-from-mount.txt"
aws s3 ls "s3://$Bucket/$Prefix" --profile $Profile --region $Region
aws s3 cp "s3://$Bucket/$ObjectKey" - --profile $Profile --region $Region
```

成功重點：

- S3 清單出現 `hello-from-mount.txt`。
- `aws s3 cp ... -` 能讀回 EC2 寫入的內容。

### 5. 這次不是 CloudFormation stack

建議保留一張說明用截圖，可選：

- CloudFormation > Stacks：沒有對應這次 CLI PoC 的 stack。
- 或保留本專案文件 `S3-Files-CLI實作流程圖-2026-07-21.md`，說明 CLI 直接建立資源不會自動出現在 CloudFormation / Infrastructure Composer。

說法：

> 本次是 CLI direct resource PoC，不是 CloudFormation-managed stack；因此 CloudFormation 不會自動畫出這套手動資源，但可以用文件流程圖說明實際架構。

## 可以用文字輸出的證據

若不方便截太多 Console 圖，保留以下去識別化 CLI 輸出也足夠：

```powershell
aws s3files list-file-systems --profile $Profile --region $Region --query "fileSystems[].{status:status,bucket:bucket,prefix:prefix}" --output table
aws ec2 describe-instances --profile $Profile --region $Region --filters Name=tag:Name,Values='s3files*' --query "Reservations[].Instances[].{State:State.Name,Type:InstanceType}" --output table
aws s3 ls "s3://$Bucket/$Prefix" --profile $Profile --region $Region
```

避免保存：

- `aws sts get-caller-identity` 的完整 ARN。
- `describe-*` 原始 JSON 全量輸出。
- EC2 key pair / `.pem` 內容。
- security credentials。

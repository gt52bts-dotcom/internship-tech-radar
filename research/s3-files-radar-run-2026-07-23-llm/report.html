Launching S3 Files, making S3 buckets accessible as file systems

AWS News Blog (explicit article input) | 2026-04-07 | avg 4.35

Amazon S3 Files lets general purpose S3 buckets be mounted as shared NFS file systems by EC2, containers, and Lambda. File changes synchronize with S3; it uses IAM, TLS, POSIX permissions, and CloudWatch/CloudTrail monitoring.

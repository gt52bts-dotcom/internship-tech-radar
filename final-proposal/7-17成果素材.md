# Final Proposal｜2026-07-17 成果素材

## 這段成果要講的一句話

7/17 的關鍵進展不是「又多部署一次」，而是把技術雷達從手動 Console 跑通，升級成公司 AWS 帳戶中可用 CloudFormation 重建、可端到端驗證、且具備治理證據與人工審核入口的版本。

## 可放進簡報的主張

### 已驗證

- 公司帳戶部署已從手動 Console 流程，推進到純 CloudFormation stack `cathay-techintel-v3-cfn` 可重建版本。
- Step Functions execution `company-cfn-001` 已成功跑完 S1 至 S5，狀態為 `SUCCEEDED`。
- 本次 pipeline 產出完整 artifacts：`report.html`、`s5_report.json`、`evidence-ledger.json`、`review-packet.json`、`decision-layer.json`、`feedback-stats.json`、`audit-packet.json`、`cost-estimate.yaml`。
- 新版 HTML 報告已可從 S3 下載開啟，並確認包含 Evidence Ledger、Human Review Gate、Budget Quotation、Pipeline Funnel 與 research disclosure。
- 離線 `evaluation_harness.py` 通過，quality gate 為 pass。

### 已實作但仍待公司環境持續驗證

- Human Review Loop 已具備資料結構與 Lambda 記錄方式，但仍需要累積多筆人工審核紀錄，才能把 `feedback-stats.json` 從少量資料變成可說明趨勢。
- Algorithmic Decision Layer 已能輸出可解釋決策分數，但目前定位是 rule-based / weighted policy，不是已訓練機器學習模型。
- CloudFormation 可重建部署已成功一次，後續若要交接，仍需確認不同操作者、不同 artifact 版本與不同權限條件下的可重跑性。

### 不能說太滿

- 本次 quote gate 為 approve，估價 `total_usd=0.0892`，但實際 LLM token 為 0；因此不能寫成「正式 Anthropic API 評分已完成」。
- 若要驗證真實 LLM 評分，需補正式 Anthropic API key，或改走公司核准的 Bedrock 路徑。
- S3 報告是 private bucket 下載檢視，不應為了展示方便改成 public bucket。

## 建議簡報頁面

### 頁面標題

從「能跑」到「能交付」：公司帳戶 CloudFormation 版技術雷達

### 三個重點

1. 可重建：不再只依賴 Console 手動步驟，改成 CloudFormation template 描述完整基礎設施。
2. 可驗證：Step Functions 在公司帳戶端到端成功，並產出可下載報告。
3. 可審核：Evidence Ledger、Human Review Gate、Decision Layer 與 Audit Packet 讓結果有證據、有邊界、有後續人工檢查入口。

### 口說稿草稿

7/17 以前，專案已經能在公司帳戶用手動 Console 方式跑通；7/17 的升級，是把這個成果往正式交付推進。因為 CDK bootstrap 會被公司 SCP 擋住，我改用純 CloudFormation，避開 `/cdk-bootstrap/.../version` 與 asset publishing role 的依賴。部署成功後，Step Functions 完整跑完 S1 到 S5，並產出報告、證據帳本、人工審核包、決策層與稽核包。這讓成果從「功能可執行」變成「可以被重建、被檢查、被交接」。
